## TP 1 - Version original du 29/01

## ⚠️ Attention au lancement du projet

Si le TP ne se lance pas correctement, c’est normal.
Pour une raison encore inconnue, lorsque les fichiers JSP sont placés dans un dossier jsp/, le projet a des difficultés à les retrouver correctement (problème de chemin / de résolution des vues)

👉 Solution :
Veuillez retirer tous les fichiers JSP du dossier jsp et les placer directement dans le dossier webapp.

Une fois les fichiers JSP remis à la racine de webapp, l’application fonctionne normalement.
